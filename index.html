印记 · lifelog-app

旅行与生活记录 · Android 8.0+

v1.9.5 versionCode 39 64 MB 2026-10-12

记旅票、地点、影视和随笔的小应用：翻相册挑图、地图上看自己的足迹，数据全部留在手机里。

  • 四类记录：旅票（机票 / 火车票 / 汽车票 / 轮船）、地点、娱乐（电影 / 剧集 / 动漫 / 游戏 / 书籍）、随笔（日记 / 事迹）
  • 地图：出行轨迹弧线 + 地点标点，同名地点自动合并成一根针；可按飞机 / 火车 / 汽车 / 轮船筛选轨迹
  • 相册零复制：只记录相册引用，不把照片复制一份进应用；实况照片点开详情页就预热，点一下立即播放
  • 本地优先：无账号、无广告、无埋点，数据只存在你自己的手机上；侧边栏可导出 / 导入备份
  • 日历视角：有活动的日期打彩色圆点，点某天只看当天
